DC Circuit Calculator (โปรแกรมคำนวณวงจรไฟฟ้ากระแสตรง)
คำอธิบาย: เครื่องมือคำนวณและวิเคราะห์วงจรตัวต้านทานตามกฎของโอห์ม (Ohm's Law) และกฎของเคอร์ชอฟฟ์ ผู้ใช้สามารถป้อนค่าแรงดันไฟฟ้า (Voltage) ความต้านทาน (Resistance) หรือกระแส (Current) เพื่อคำนวณค่าพารามิเตอร์ที่เหลือ รวมถึงกำลังไฟฟ้า (Power) ได้อย่างรวดเร็วและแม่นยำ

วัตถุประสงค์: อำนวยความสะดวกในการคำนวณค่าทางไฟฟ้า ลดความผิดพลาดจากการคำนวณด้วยมือ และใช้เป็นเครื่องมือสนับสนุนการเรียนรู้หรือช่วยในการออกแบบวงจรไฟฟ้าเบื้องต้น

วิธีใช้งาน:
1. เปิด Terminal หรือ Command Prompt
2. ไปที่โฟลเดอร์โปรเจ็กต์
3. รันคำสั่ง: python electrical.py
4. เลือกเมนูที่ต้องการจากรายการ

สูตรพื้นฐานที่ใช้:
- V = I × R
- I = V / R
- R = V / I
- P = V × I
- รวมนำในวงจรอนุกรม: R_total = R1 + R2 + ...
- รวมนำในวงจรขนาน: 1 / R_total = 1/R1 + 1/R2 + ...
